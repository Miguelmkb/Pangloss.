# Pangloss

Revista digital de ensayo, análisis e ideas. React + TypeScript + Vite + Tailwind + Supabase.

## Estado del proyecto

- **Fase 1 — Arquitectura:** cerrada.
- **Fase 2 — Base del proyecto:** en curso (routing, layouts, design tokens).
- **Fase 3 en adelante:** Supabase, sitio público con datos reales, panel, editor, tests, despliegue.

Ver el historial de conversación del proyecto para el detalle de cada fase.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`.

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run typecheck` — comprobación de tipos sin emitir
- `npm run lint` — ESLint

## Estructura

Ver `src/` para componentes/páginas/lib, y `supabase/migrations` para el esquema de base de datos (Fase 3).
